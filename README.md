A one-line entry for the "Rename the Planet" bounty: one funny new name for a planet in our solar system, plus the why, in a single line. Mercury becomes "Mood Swings" — it swings from -180C at night to 430C by day and never once apologizes. The program validates the line (at most 200 characters, ASCII, single line) and writes it to `entry.txt`.

## Run it

```sh
python3 main.py
```
